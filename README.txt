# EMI Calculator PWA

This is a real installable Progressive Web App.

Features:
- Loan amount input
- Automatic 4.13% processing fee
- Insurance: ₹20,000 for ₹5 lakh and below; ₹24,500 above ₹5 lakh
- Automatic IRR from the supplied SAL/SEMP + New/PLTB rate table
- Tenure 0–100 months, with quick buttons 33/36/42/48/51/63
- EMI, total interest and total repayment
- Amortization schedule
- Download Result as PNG with date/time
- Installable on Android from Chrome

IMPORTANT:
For PWA installation, host the folder on HTTPS (for example GitHub Pages). Opening index.html directly from a phone file manager will run the calculator but normally will not enable PWA installation/service-worker features.
